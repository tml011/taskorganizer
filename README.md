# TaskOrganizer

Простой органайзер для повседневных задач на Android.

## Возможности

- добавление и редактирование задач;
- поиск по задачам;
- фильтрация списка;
- экран настроек;
- хранение данных на устройстве — интернет не нужен.

## Установка

Скачайте `TaskOrganizer.apk` из [последнего релиза](https://github.com/tml011/taskorganizer/releases/latest) и установите на Android-устройство. При установке может потребоваться разрешить установку из неизвестных источников.
